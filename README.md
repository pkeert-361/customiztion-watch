⌚ DIGI TIME — Luxury Digital Watches

Your Time, Your Style

A modern, single-file responsive web application for Digi Time Watches. It combines an interactive luxury digital watch storefront (priced in Indian Rupees ₹) with a full-stack architecture roadmap covering Frontend, Backend, and Database integration.

✨ Key Features

Live Digital Chronograph Showcase: Real-time working clock, date display, and simulated biometric telemetry (BPM & 100M depth rating) styled in a luxury bezel.

Featured Watch Catalog: Displays precision digital timepieces with transparent pricing in Indian Rupees (₹) and one-click Buy Now actions.

Interactive Shopping Bag Drawer: Slide-over cart with real-time item quantity updates, subtotal calculation in ₹, item removal, and simulated checkout confirmation.

Bespoke Studio Customizer: Live bezel theme switcher allowing users to preview Stealth Obsidian, Crimson Titanium, and 24K Champagne Gold finishes directly on the hero watch dial.

Full-Stack Architecture Roadmap:

Module 01 – Frontend Development: Responsive UI/UX, live telemetry, and interactive cart state.

Module 02 – Backend Development: Includes a working client-side deliverable submission form with instant input validation and timestamp logging.

Module 03 – Database Integration: Blueprint for product inventory, user accounts, and order persistence.

One-Click HTML Copy: Built-in Copy HTML button in the header for easy source code duplication.

🛠️ Technologies Used

HTML5: Semantic structure for navigation, hero showcase, product grids, and interactive drawers.

Tailwind CSS (CDN): Utility-first responsive styling with custom navy (#0d1321 / #151d31) and crimson (#a51e49 / #c82358) color tokens, plus glassmorphism effects.

Google Fonts & Font Awesome: Orbitron for digital chronograph displays, Inter for clean UI typography, and crisp vector icons.

Vanilla JavaScript (ES6+): Powers the live clock, dynamic catalog rendering, shopping cart state, toast notifications, and form validation with zero external framework dependencies.

🚀 Getting Started

Because the entire application is self-contained inside index.html, no build tools, Node.js packages, or local servers are required:

Download or Copy: Save the website code as index.html.

Launch: Open index.html in any modern web browser (Chrome, Edge, Firefox, or Safari).

Deploy (Optional): Upload index.html directly to GitHub Pages, Netlify, or Vercel for instant live hosting.
